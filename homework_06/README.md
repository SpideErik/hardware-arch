## Дай определение терминам:

1. **DDR** (расшифруй аббревиатуру и объясни смысл)
> Double Data Rate (удвоенная скорость передачи данных) - полное название DDR SDRAM. Как и обычная SDRAM, DDR SDRAM хранит данные в ячейках, содержащих конденсаторы и транзисторы. Работа памяти синхронизирована с тактовым сигналом (Clock). Главное отличие DDR заключается в том, что передача данных осуществляется по обоим фронтам тактового сигнала — переднему и заднему. Благодаря этому DDR может передавать данные в два раза чаще, чем SDR SDRAM, при одинаковой частоте тактового сигнала.

2. **DIMM** — что это?
> Dual In-line Memory Module - формат модуля памяти. В отличии от SIMM контакты на разных сторонах платы разделены и передают разные сигналы. Обычно разрядность шины данных 64 бит (или 2x32 бит в DDR5). Один модуль полностью обеспечивает нужную разрядность.

3. **Ранг (rank)** — что это?
> Ранг памяти — это группа микросхем DRAM на модуле, которые совместно обслуживают один 64-битный интерфейс данных (у обычного DDR4 DIMM). 

> Использование нескольких рангов позволяет
- Больше ёмкость. Можно разместить больше микросхем на одном модуле.
- Дополнительные возможности планирования. Пока один ранг занят некоторыми операциями, контроллер может организовать работу с другим рангом, если позволяют состояние шины и ограничения протокола.
- Возможность перекрывать задержки. Контроллер иногда может начать операцию с другим рангом, пока предыдущий ранг завершает внутреннюю операцию.
> Но важно: два ранга — это не удвоенная ширина шины. Если интерфейс 64-битный, он остаётся 64-битным.

4. **CAS Latency (CL)** — что показывает?
> Column Address Strobe Latency это задержка в тактах между подачей команды чтения READ и началом выдачи запрошенных данных из динамической памяти DRAM. CL показывает, сколько тактовых циклов проходит до начала передачи данных при условии, что нужная строка памяти уже открыта. Чем меньше CL при одинаковой частоте тактового сигнала, тем меньше задержка чтения.

5. **Тайминги** — что это такое?
> временные параметры оперативной памяти, определяющие минимальные задержки между командами и длительность выполнения определённых операций. Обычно они указываются в тактах тактового сигнала. Основные тайминги часто записывают в виде `CL – tRCD – tRP – tRAS` (например, `16-18-18-38`):


- **CL** — задержка от команды чтения до начала выдачи данных.
- **tRCD** — минимальное время от активации строки до команды чтения или записи.
- **tRP** — минимальное время, необходимое для закрытия строки перед открытием другой строки в том же банке.
- **tRAS** — минимальное время, в течение которого строка должна оставаться активной после активации.

> Кроме таймингов, указывают скорость передачи данных памяти (MT/s). Чем меньше задержки в наносекундах при сопоставимых условиях, тем быстрее память может выполнить соответствующую операцию.


6. **Двухканальный режим** — зачем нужен?

> Технология работы оперативной памяти, которая используется для удвоения пропускной способности шины данных между процессором и оперативной памятью.

- В одноканальном режиме данные передаются по одной магистрали разрядностью 64 бита.
- В двухканальном режиме материнская плата объединяет два физических модуля памяти, расширяя общую шину данных до 128 бит. Данные начинают передаваться параллельно по двум независимым каналам одновременно, что ровно в два раза увеличивает теоретическую пропускную способность.
-  Два модуля памяти одинакового объема (например, две планки по 8 ГБ) в двухканальном режиме всегда будут работать быстрее, чем один модуль большого объема 16 ГБ в одноканальном режиме, хотя итоговый объем памяти будет одинаковым.
- Критически важен для встроенной графики потому что процессоры со встроенным видеоядром не имеют собственной видеопамяти и используют оперативную.

> В реальности производительность всей системы увеличивается в среднем на 10–25%, а не в 2 раза. В два раза вырастает только чистая скорость копирования данных в синтетических тестах.
